## Descripción para el portafolio

Eventario es una aplicación web que centraliza la organización de eventos, desde la publicación hasta el ingreso de los asistentes. Los organizadores pueden gestionar el aforo, asignar personal y validar entradas mediante códigos QR. Los asistentes pueden consultar los eventos disponibles, inscribirse y acceder a sus entradas digitales. La plataforma también admite eventos pagos y solicitudes de reembolso.

El proyecto busca simplificar el registro y el control de asistencia al reunir en un solo sistema las inscripciones, las entradas y la validación de acceso.

## Stack tecnológico

- **Frontend** — React, TypeScript, Vite y Tailwind CSS.
- **Backend** — Java 21 y Spring Boot para la API REST. Spring Security y JWT para la autenticación y el control de acceso por roles.
- **Base de datos** — PostgreSQL con migraciones gestionadas por Flyway.
- **Integraciones** — Stripe para pagos y Google OAuth 2.0 para el inicio de sesión.
